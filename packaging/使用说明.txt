LiteFences 桌面启动器 · 使用说明
================================

安装（推荐 MSI）
----------------
1. 双击 `LiteFences-x.y.z-x64.msi`（或右键 → 安装），一路下一步即可。
   装完第一次打开面板会有一张说明卡（拖动、拖入、收起三句话），点「知道了」或直接关掉，
   以后不会再出现。
2. 按用户安装到 `%LOCALAPPDATA%\Programs\LiteFences`，创建：
   - 开始菜单快捷方式「LiteFences」
   - 桌面快捷方式「LiteFences」
   - 「设置 → 应用 → 已安装的应用」里的卸载项（和 MSI 的修复/卸载共用）
3. **卸载走系统正常途径**：「设置 → 应用 → 已安装的应用」找到 LiteFences → 卸载；
   或者在「开始菜单」右键 LiteFences → 卸载。也可以重新运行同一个 MSI，
   会进入「修复 / 卸载」维护界面。
   个人配置（布局、分组、日志）在 `%LOCALAPPDATA%\LiteFencesDesktop`，卸载不会删；
   想彻底清干净，卸载后手动删掉这个目录即可。
4. 不需要管理员权限，全部写在当前用户下。

安装向导语言
------------
MSI 的安装向导是简体中文（欢迎、许可、进度、完成、修复/卸载都是中文）。
想生成英文向导的包，构建时加 `-Culture en-us`（界面语言仍由程序自己的设置决定）。

语言 / Language
---------------
面板左上角「设置」或托盘菜单 →「语言」：跟随系统 / 中文 / English。
选「跟随系统」时中文系统用中文，其它语言的系统用英文；选择会存进 config.json 的 settings.lang。
设置菜单 / Tray menu → Language: Follow system / 中文 / English.

便携用法
--------
不想安装的话，直接双击 `LiteFencesDesktop.exe` 即可（配置一样存在
`%LOCALAPPDATA%\LiteFencesDesktop`）。这种情况没有开始菜单/卸载项，
关掉程序后删掉文件夹就算卸载。

关于 SmartScreen
----------------
程序没有代码签名，每次换新版本第一次运行时 Windows 可能提示「已保护你的电脑」，
点「更多信息 → 仍要运行」即可；这不会影响功能。

怎么用
------
1. 唤出：按 Ctrl+Alt+Space；或点通知区图标；或在桌面空白处双击。
2. 面板背景是你桌面"模糊后"的样子（唤出瞬间抓屏再模糊，不依赖系统亚克力），并带 0.2 秒淡入动画。
3. 「单击」任意图标 → 用系统默认程序打开它，面板自动收起。
4. 「拖动」图标到别的格子松手 → 换位；顺序会保存。
5. 「单击」空白处，或按 Esc → 收起面板，桌面图标恢复原样。
6. 退出：通知区图标右键 → “退出 LiteFences”，或按 Ctrl+Alt+Q。
7. 面板左上角「设置」= 同一个托盘菜单（热键、自启、主题、图标大小、语言、导入导出配置、检查更新、退出），
   旁边「＋ 新建分组」= 建一个空组，右上角「全部折叠 / 全部展开」= 一键切换普通分组状态，
   最右侧「移除」= 移除模式开关，中间放大镜 = 搜索（也可以唤出后直接敲字母/数字，Esc 清除）。
8. 右键图标 = 「重命名…」「更换图标…」「恢复默认图标」「以管理员身份运行」「打开所在位置」「属性」
   「复制路径」或「移到『某组』」；右键分组标题 = 重命名/折叠/全部折叠或展开/自动归组规则/删除该组，
   文件夹入口则提供「在资源管理器中打开」「刷新该入口」「返回上一级」「回到入口根目录」和排序。
9. 图标多到一屏放不下时：面板右侧会出现细滚动条，用鼠标滚轮上下翻（面板不抢焦点，
   滚轮指到面板上就能滚）；不超高时不会出现滚动条。滚动时当前分组的标题会吸在顶部。
10. 文件夹入口：面板左上角「设置」→「添加文件夹入口…」，选一个文件夹，面板里就多出
    「入口：目录名」一组，显示该文件夹里的东西。点击子目录可在入口内直接进入下一级浏览，
    标题栏会显示当前相对路径及右侧「← 上一级」按钮（非搜索态也可按 Backspace 返回上一级）；
    右键标题可手动「刷新该入口」「返回上一级」「回到入口根目录」。入口是**只读视图**：
    不能拖动/改名/换图标，删掉入口也不会动文件夹里的文件。
11. 入口排序：右键入口标题 → 「排序：文件夹在前，再按名称 / 按名称 / 按修改时间（新的在前）」，
    当前用的那项前面有勾；改完立刻生效。
12. 换配色：面板左上角「设置」（或托盘菜单）→「主题：…」，五个预设：
    深空蓝（默认）/ 石墨灰 / 午夜紫 / 森林绿 / 暖砂（浅色）。选中的那项前面有勾，
    存在 config.json 的 settings.theme 里。界面立刻变，磨砂底的色调下次唤出生效。
13. 图标大小：面板左上角「设置」（或托盘菜单）→「图标大小：」→「紧凑 / 标准 / 偏大」，
    写入 config.json 的 settings.icon_density 并立刻重排生效。
14. 配置导入 / 导出：面板左上角「设置」（或托盘菜单）→「导出配置…」「导入配置…」，
    可导出为 JSON 备份或从已有 JSON 恢复配置；导入前会校验格式并保留原有 config.json.bak，
    确认后立刻热重载生效。

搜索
----
- 面板唤出后直接敲字母或数字就进入搜索，不用先点放大镜；Backspace 删字，删空后再按一次收起搜索。
- 支持名称子串、中文全拼、拼音首字母、英文单词首字母：bdwp → 百度网盘，wx → 微信，
  vsc → Visual Studio Code，chongqing / cq → 重庆。
- 多音字按全部常见读音匹配：重庆（chongqing / zhongqing）、长江（changjiang / zhangjiang）、
  银行（yinhang / yinxing）。
- 支持点号开头的文件后缀筛选（如 .pdf、.exe），以及输入分组名或分组拼音找出该组全部图标。
- 程序会记录每个图标的打开次数与最近使用时间，搜索结果同分时常用项自动排在前面。
- 命中项按相关度排成紧凑网格：方向键选，Enter 打开，Esc 清除。没有结果时显示「没有匹配的图标」。
- 直接敲字母可搜全拼和首字母。点击放大镜或已展开的搜索栏可以输入或粘贴汉字。选词时 Enter 确认候选词，上屏后 Enter 打开当前结果。

多选整理
--------
- 普通点击选中一个；Ctrl 点选增减，Shift 按当前顺序连选。
- 拖动任意已选项 → 整组一起移动，松手落到目标分组即批量移入。
- 同组内拖到目标图标上可以批量排序。向前拖放在目标之前，向后拖放在目标之后，所选图标保持原有顺序。Ctrl+Z 撤销整批移动。
- Ctrl+C → 复制当前选中项路径（支持多选和搜索结果）；Ctrl+Shift+Enter → 以管理员身份运行选中项。
- Delete → 从面板批量移除（只取消引用，不删源文件）；Esc → 取消多选。
- 多选后右键 → 「打开所在位置」「属性」「复制 N 条路径」「从面板移除所选 N 项」。
- Ctrl+Z → 撤销最近一次移动、移除、重命名、换图标或分组改动（最多保留 20 步）；Ctrl+Y / Ctrl+Shift+Z → 重做。

添加 / 移除图标（都在面板里完成，不切出去）
-------------------------------------------
- 拖入：在资源管理器里选中文件/文件夹/快捷方式，直接拖到面板上松手即加入。
  拖的时候松手位置所在的分组会整块描边高亮，列进该组；底部会提示「加入 N 项 / 跳过 N 项」。
  只记录路径引用，**不会移动、复制或删除原文件**；已经在面板里的会自动跳过。
- 添加：点网格最后的「＋ 添加图标」。面板不会关，系统选择框会叠在上面；
  选完文件后新图标直接出现在网格末尾。
- 移除：点右上角「移除」开关（变红显示“移除中”），然后**单击任意图标**即从面板移除；
  再点一次开关或按 Esc 退出移除模式。
  手动图标会从配置里的 custom 列表删除；桌面图标会记到 hidden 列表（桌面上的文件不动）。
  想恢复被隐藏的桌面图标：从 config.json 的 hidden 里删掉对应路径，重启程序即可。
- 配置统一存在 %LOCALAPPDATA%\LiteFencesDesktop\config.json：
  custom（手动添加的图标）、items（面板顺序 + 显示名 + 自定义图标）。

分组
----
- 面板按分组分节显示，每组一行标题（箭头 + 组名 + 图标数量）。
- 点标题行**任意位置** → 带逐行动画折叠 / 展开该组（动画中途再点可立刻反向），状态自动保存；
  顶部右上角按钮、标题右键或 Ctrl+Shift+C / Ctrl+Shift+E 可一键全部折叠 / 全部展开。
- 按住标题行上下拖 → 调整分组顺序，会有一条蓝色插入线指示落点，顺序写进 config.json。
- 右键任意图标 → 菜单里选「移到『某组』」，或「新建分组并移入…」（填个名字即可）。
- 更快的做法：**把图标直接拖到某个组的标题行上松手**，标题会先高亮，松手即移入。
- 右键分组标题 → 「重命名分组…」「折叠/展开该组」「全部折叠/全部展开」「自动归组规则…」「删除该分组（图标回到『其它』）」。
- 普通非默认分组支持「自动归组规则…」：可填扩展名（如 .pdf, .xlsx）或关键字（如 会议），
  用逗号或空格分隔；保存后立刻整理未归组及「其它」组里的匹配项，后续扫描与新增也会自动归类，
  但不会覆盖手动移入别的分组的图标，改错可按 Ctrl+Z 撤销。
- 没有归组的图标自动落在最后的「其它」组；添加按钮也在这个组末尾。
- 分组数据在 config.json 的 groups 里，长这样：
      "groups": [
        { "name": "开发", "collapsed": false, "paths": ["C:\\...\\Code.lnk"], "rules": [".pdf", "周报"] },
        { "name": "其它", "collapsed": true,  "paths": [] }
      ]
  JSON 可以直接手改（注意转义反斜杠），重启生效。主配置损坏时会留存 config.broken.json，并优先从有效的 config.json.bak 恢复。
  手动图标和文件夹入口在设备断开时标记为「暂不可用」，保留名称、分组和排序。唤出面板或设备插拔时会在后台异步检测并刷新。

托盘菜单
--------
- 打开 / 隐藏图标面板
- 开机自启（已开启/已关闭）  ← 点一下切换，只写 HKCU Run 里本项目一个值
- 设置唤出热键…（当前 Ctrl+Alt+Space）  ← 弹出小窗，直接按下想要的组合键
- 添加文件夹入口…（只读展示目录内容）
- 主题：深空蓝（默认）/ 石墨灰 / 午夜紫 / 森林绿 / 暖砂（浅色）
- 图标大小：紧凑 / 标准 / 偏大  ← 调整图标与网格尺寸，立刻重排
- 语言：跟随系统 / 中文 / English
- 导出配置… / 导入配置…  ← 导出或导入 JSON 配置（导入前保留 config.json.bak 并热重载）
- 检查更新…  ← 请求 GitHub Releases；发现新版本会用托盘气泡提示，点气泡打开下载页
- 自动检查更新（已开启/已关闭）  ← 控制启动时是否检查；状态存 config.json 的 settings.check_updates
- 退出 LiteFences

快捷键
------
Ctrl+Alt+Space   唤出 / 收起（可在托盘菜单里改，存进 config.json 的 settings）
Ctrl+Alt+Q       退出
字母 / 数字      唤出后直接搜索（支持拼音、英文缩写、.ext 后缀、分组名）
Backspace        删除搜索字符；删空后再按一次收起搜索；非搜索态下返回文件夹入口上一级
方向键           在图标或搜索结果之间移动
Enter            打开选中项
Ctrl+Shift+Enter 以管理员身份运行选中项
Tab / Shift+Tab  跳到下一个 / 上一个分组
Ctrl / Shift 点选 多选图标（Ctrl 增减，Shift 连选）
Ctrl+C           复制选中图标路径（支持多选）
Ctrl+Shift+C / Ctrl+Shift+E  全部折叠 / 全部展开分组
Delete           从面板移除所选图标（不动源文件）
Ctrl+Z           撤销最近改动（最多 20 步）
Ctrl+Y / Ctrl+Shift+Z  重做
Esc              取消多选 / 清除搜索；再按一次收起

可选参数（加在快捷方式的目标后面）
----------------------------------
--blur=frost|accent|dim|off   背景方式：默认 frost（自绘磨砂底板）
--no-hide-desktop-icons       面板显示期间不隐藏原生桌面图标
--show-ms=3000                启动即显示面板 3 秒后退出（演示用）
--autostart=on|off            直接设置开机自启
--self-test                   不开界面，自检并写报告
--drop-test="C:\某个文件"      把该路径当成一次拖入投给面板，验证拖放后退出（排障）
--select=1,2,3                启动时选中多个图标（配合 --capture 截图）
--search-test=关键字           模拟直接打字搜索，日志打印命中数（排障）
--update-test                 同步检查一次更新并写日志后退出（排障）

数据与日志
----------
%LOCALAPPDATA%\LiteFencesDesktop\config.json        全部配置（JSON，带 version 字段）
%LOCALAPPDATA%\LiteFencesDesktop\config.json.bak    上一次保存前的备份
%LOCALAPPDATA%\LiteFencesDesktop\launcher.log        运行日志（最大 512 KB）
%LOCALAPPDATA%\LiteFencesDesktop\icons-hidden.flag   面板显示期间存在；残留时下次启动自动恢复桌面图标

旧版本的 layout.txt / groups.txt / portals.txt / settings.txt / custom-icons.txt / hidden-icons.txt
会在首次启动时自动迁移进 config.json，原文件改名成 *.migrated 留底。

自定义图标
----------
- 右键图标 →「更换图标…」→ 选一个 .ico 文件；面板上就用它显示（不动源文件）。
- 右键 →「恢复默认图标」可以还原。
- 记录写在 config.json 的 items 里（icon 字段）。
