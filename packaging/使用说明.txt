LiteFences 桌面启动器 · 使用说明
================================

安装（推荐 MSI）
----------------
1. 双击 `LiteFences-x.y.z-x64.msi`（或右键 → 安装），一路下一步即可。
2. 按用户安装到 `%LOCALAPPDATA%\Programs\LiteFences`，创建：
   - 开始菜单快捷方式「LiteFences」
   - 桌面快捷方式「LiteFences」
   - 「设置 → 应用 → 已安装的应用」里的卸载项（和 MSI 的修复/卸载共用）
3. **卸载走系统正常途径**：「设置 → 应用 → 已安装的应用」找到 LiteFences → 卸载；
   或者在「开始菜单」右键 LiteFences → 卸载。也可以重新运行同一个 MSI，
   会进入「修复 / 卸载」维护界面。
   个人配置（布局、分组、日志）在 `%LOCALAPPDATA%\LiteFencesDesktop`，卸载不会删；
   想彻底清干净，卸载后手动删掉这个目录即可。
4. 不需要管理员权限，全部写在当前用户下。

安装向导语言
------------
MSI 的安装向导是简体中文（欢迎、许可、进度、完成、修复/卸载都是中文）。
想生成英文向导的包，构建时加 `-Culture en-us`（界面语言仍由程序自己的设置决定）。

语言 / Language
---------------
面板左上角「设置」或托盘菜单 →「语言」：跟随系统 / 中文 / English。
选「跟随系统」时中文系统用中文，其它语言的系统用英文；选择会存进 settings.txt 的 lang=。
设置菜单 / Tray menu → Language: Follow system / 中文 / English.

便携用法
--------
不想安装的话，直接双击 `LiteFencesDesktop.exe` 即可（配置一样存在
`%LOCALAPPDATA%\LiteFencesDesktop`）。这种情况没有开始菜单/卸载项，
关掉程序后删掉文件夹就算卸载。

关于 SmartScreen
----------------
程序没有代码签名，每次换新版本第一次运行时 Windows 可能提示「已保护你的电脑」，
点「更多信息 → 仍要运行」即可；这不会影响功能。

怎么用
------
1. 唤出：按 Ctrl+Alt+Space；或点通知区图标；或在桌面空白处双击。
2. 面板背景是你桌面"模糊后"的样子（唤出瞬间抓屏再模糊，不依赖系统亚克力），并带 0.2 秒淡入动画。
3. 「单击」任意图标 → 用系统默认程序打开它，面板自动收起。
4. 「拖动」图标到别的格子松手 → 换位；顺序会保存。
5. 「单击」空白处，或按 Esc → 收起面板，桌面图标恢复原样。
6. 退出：通知区图标右键 → “退出 LiteFences”，或按 Ctrl+Alt+Q。
7. 面板左上角「设置」= 同一个托盘菜单（热键、自启、抓图、退出），
   旁边「＋ 新建分组」= 建一个空组，右上角「移除」= 移除模式开关，
   中间放大镜 = 搜索（点开后输入，Esc 清除）。
8. 右键图标 = 「重命名…」改显示名、「更换图标…」换一个 .ico、「恢复默认图标」、
   或「移到『某组』」；右键分组标题 = 重命名/折叠/删除该组。
9. 图标多到一屏放不下时：面板右侧会出现细滚动条，用鼠标滚轮上下翻（面板不抢焦点，
   滚轮指到面板上就能滚）；不超高时不会出现滚动条。滚动时当前分组的标题会吸在顶部。
10. 文件夹入口：面板左上角「设置」→「添加文件夹入口…」，选一个文件夹，面板里就多出
    「入口：目录名」一组，显示该文件夹里的东西。这是**只读视图**：不能拖动/改名/换图标，
    删掉入口也不会动文件夹里的文件。
11. 入口排序：右键入口标题 → 「排序：文件夹在前，再按名称 / 按名称 / 按修改时间（新的在前）」，
    当前用的那项前面有勾；改完立刻生效。
12. 换配色：面板左上角「设置」（或托盘菜单）→「主题：…」，五个预设：
    深空蓝（默认）/ 石墨灰 / 午夜紫 / 森林绿 / 暖砂（浅色）。选中的那项前面有勾，
    存在 settings.txt 的 theme= 里。界面立刻变，磨砂底的色调下次唤出生效。

添加 / 移除图标（都在面板里完成，不切出去）
-------------------------------------------
- 拖入：在资源管理器里选中文件/文件夹/快捷方式，直接拖到面板上松手即加入。
  拖的时候松手位置所在的分组会整块描边高亮，列进该组；底部会提示「加入 N 项 / 跳过 N 项」。
  只记录路径引用，**不会移动、复制或删除原文件**；已经在面板里的会自动跳过。
- 添加：点网格最后的「＋ 添加图标」。面板不会关，系统选择框会叠在上面；
  选完文件后新图标直接出现在网格末尾。
- 移除：点右上角「移除」开关（变红显示“移除中”），然后**单击任意图标**即从面板移除；
  再点一次开关或按 Esc 退出移除模式。
  手动图标会从配置里的 custom 列表删除；桌面图标会记到 hidden 列表（桌面上的文件不动）。
  想恢复被隐藏的桌面图标：从 config.json 的 hidden 里删掉对应路径，重启程序即可。
- 配置统一存在 %LOCALAPPDATA%\LiteFencesDesktop\config.json：
  custom（手动添加的图标）、items（面板顺序 + 显示名 + 自定义图标）。

分组
----
- 面板按分组分节显示，每组一行标题（箭头 + 组名 + 图标数量）。
- 点标题行**任意位置** → 折叠 / 展开该组，状态自动保存（以前只有左边「箭头 + 组名」能点）。
- 按住标题行上下拖 → 调整分组顺序，会有一条蓝色插入线指示落点，顺序写进 config.json。
- 右键任意图标 → 菜单里选「移到『某组』」，或「新建分组并移入…」（填个名字即可）。
- 更快的做法：**把图标直接拖到某个组的标题行上松手**，标题会先高亮，松手即移入。
- 右键分组标题 → 「重命名分组…」「折叠/展开该组」「删除分组（图标回到『其它』）」。
- 没有归组的图标自动落在最后的「其它」组；添加按钮也在这个组末尾。
- 分组数据在 config.json 的 groups 里，长这样：
      "groups": [
        { "name": "开发", "collapsed": false, "paths": ["C:\\...\\Code.lnk"] },
        { "name": "其它", "collapsed": true,  "paths": [] }
      ]
  JSON 可以直接手改（注意转义反斜杠），改完重启程序生效；改坏了程序会自动备份成
  config.broken.json 并回到默认配置，不会打不开。

托盘菜单
--------
- 打开 / 隐藏图标面板
- 开机自启（已开启/已关闭）  ← 点一下切换，只写 HKCU Run 里本项目一个值
- 设置唤出热键…（当前 Ctrl+Alt+Space）  ← 弹出小窗，直接按下想要的组合键
- 抓取面板画面（排障）
- 退出 LiteFences

快捷键
------
Ctrl+Alt+Space   唤出 / 收起（可在托盘菜单里改，存进 config.json 的 settings）
Ctrl+Alt+F12     抓取当前面板（排障）
Ctrl+Alt+Q       退出
Esc              收起

可选参数（加在快捷方式的目标后面）
----------------------------------
--blur=frost|accent|dim|off   背景方式：默认 frost（自绘磨砂底板）
--no-hide-desktop-icons       面板显示期间不隐藏原生桌面图标
--show-ms=3000                启动即显示面板 3 秒后退出（演示用）
--autostart=on|off            直接设置开机自启
--self-test                   不开界面，自检并写报告
--drop-test="C:\某个文件"      把该路径当成一次拖入投给面板，验证拖放后退出（排障）

数据与日志
----------
%LOCALAPPDATA%\LiteFencesDesktop\config.json        全部配置（JSON，带 version 字段）
%LOCALAPPDATA%\LiteFencesDesktop\config.json.bak    上一次保存前的备份
%LOCALAPPDATA%\LiteFencesDesktop\launcher.log        运行日志（最大 512 KB）
%LOCALAPPDATA%\LiteFencesDesktop\icons-hidden.flag   面板显示期间存在；残留时下次启动自动恢复桌面图标

旧版本的 layout.txt / groups.txt / portals.txt / settings.txt / custom-icons.txt / hidden-icons.txt
会在首次启动时自动迁移进 config.json，原文件改名成 *.migrated 留底。

当前进度：M1（形态版）+ M2（分组容器、外部拖入）已完成，正在做稳定性（M3）。
自定义图标
----------
- 右键图标 →「更换图标…」→ 选一个 .ico 文件；面板上就用它显示（不动源文件）。
- 右键 →「恢复默认图标」可以还原。
- 记录写在 config.json 的 items 里（icon 字段）。
