# P2-02a：分组重命名数据链路

2026-09-24。按开发计划书的 P2“创建、命名、移动……”顺序实现重命名数据链路，随后增加原生列表、名称输入框和提交按钮。**隐藏控件自检通过，但可见视觉和真实键盘验收未完成，P2-02 仍不算完整。**

纯 Rust `rename_group` 先校验整份配置、新标题及目标 ID，失败不修改配置；成功只更新目标分组标题，返回旧标题供保存失败时回退。稳定 ID、位置、颜色、折叠状态、引用及 ID 分配器不变。空白、控制字符和超过 128 个 Unicode 字符的标题被拒绝；不存在的 ID 返回 `NotFound`。

UI 会话层可提交重命名并调用既有后台工作线程自动保存。保存成功后保留新名称；提交失败、文件保存失败或后台线程中断时恢复旧名称。加载中、只读、保存中及正在退出时不接受新操作。普通窗口使用原生可滚动列表选择已有分组，编辑“新名称”后点击按钮提交；列表按配置顺序显示，创建后选中新组，保存期间禁用提交按钮并按既有策略交接键盘焦点。隐藏窗口的 `--storage-smoke rename` 仅在显式 `--data-dir` 下对第一个已存在分组改名；`--storage-smoke ui-rename` 用真实列表、输入框和按钮命令改第二组，不是普通用户入口。
