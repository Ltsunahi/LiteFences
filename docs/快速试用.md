# 最新版怎么用

程序：`E:\note\LiteFences\target\release\litefences.exe`。旧窗口不会自动更新，请先正常关闭旧 LiteFences，再双击这个程序。默认只读写 `%LOCALAPPDATA%\LiteFences` 的软件配置，不会搬动桌面文件。

1. Ctrl+N 建两个分组。先用“添加文件引用…”或“添加目录引用…”加入一两个项目；也可以拖入预览分组。原文件保留在原位置。
2. 单击图标，然后点“打开所在位置”，Explorer 会选中文件/目录/快捷方式本身。双击或 Enter 才是正常打开；根目录定位暂不支持。
3. 移到另一组：单击图标，在右上方下拉框选目标，点“移至目标分组”。保存成功后点左侧目标组查看，图标位于该组末尾。重复路径会拒绝，不分配新 ID。
4. 也已接入图标拖到另一组：按住图标拖入另一组后松开。Esc 取消，源文件不移动。此路径通过原生隐藏回归，真人鼠标复验仍待完成；当前已实际验收的是第 3 步按钮路径。
5. “引用前移/后移”调整组内顺序，自动保存。Ctrl+S 可主动保存，Esc 在无拖动/确认时正常退出，等待保存完成。

如果分组标题有项目数量但图标看不到，先选该组，把高度调到至少 240 DIP、适当增大宽度，然后“应用尺寸”。预览还会随全部分组范围缩放；较小尺寸可能容不下完整图标行，每组最多显示 24 项，分页/滚动未完成。不要因此重复添加同一路径。

当前是普通窗口的可运行原型，不是贴在桌面上的成品。托盘、桌面融合、通知式更新、多屏/DPI 和完整性能验收尚未完成。图标组间拖动的可见验收因旧测试窗口最小化及真人输入守卫暂停；无需再重复测试已通过的定位和按钮移动。如果愿意继续自动验收，只需还原 LiteFences 测试窗口并回复“已还原”。
