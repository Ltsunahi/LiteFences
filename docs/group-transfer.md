# 组间移动引用

点选源分组中的图标，在预览上方下拉框选择目标分组，再点击“移至目标分组”。原引用追加到目标组末尾，保留 ID、路径和类型，不移动磁盘上的文件。点击左侧目标分组可以查看移动后的图标。接受移动后清除原 tile 选择，避免位置变化导致误打开其它项目。

同组不执行移动；不存在的组/引用及目标组已有相同 UTF-16 路径均拒绝，配置保持不变。路径去重目前是无损路径的精确比较，不等于识别大小写别名、硬链接或所有等价路径。下拉框与当前预览最多列出 128 组；预览每组最多 24 项，分页/滚动尚未完成。

移动复用后台配置保存，保存中、加载中、关闭中和只读状态禁止提交。仅保存一份待确认的源组 ID、引用 ID、目标组 ID、原索引；提交/保存失败或后台中断时移回源组原位置。已有移除撤销记录不被移动消费；Ctrl+Z 仍仅恢复最近一次成功移除/删除，不是通用移动撤销。

低成本 gpt-6-luna agent 实现纯规则和独立会话测试；主 agent 审查并修正重复路径测试选错 ID、只读保护断言，再接入真实 Win32 控件。测试覆盖成功保存及重启回读、源字节不变、同组/无效组/重复路径/忙碌/只读拒绝、保存冲突恢复原顺序、后台断线两条回退路径。没有新增依赖、线程或源文件操作。

## 后续：组内图标拖动

新增鼠标路径：按下图标只选择；任一轴移动达到 4 DIP（按 DPI 上整且至少 4 像素）后进入拖动。在另一分组上悬停高亮，松开调用同一 Session 转移命令。组标题仍移动整个分组，手柄仍缩放；引用拖动只保留稳定 ID 和少量手势状态，不复制源路径。

Esc、捕获丢失、窗口失活/尺寸或 DPI 变化均取消待拖动；在同组或预览空白松开不保存。进入拖动后按 Enter 只取消，不同时启动文件。保存失败仍按按钮路径回退原组与顺序。此能力没有新增线程、crate 或源文件操作。
