# P2-08a：添加本地项目引用的数据链路

2026-09-25。此阶段只实现数据、保存与回退，不包含文件选择器、Explorer 拖入或真实桌面面板。`add_references` 对单个分组批量加入文件路径引用，不打开、移动、复制或删除源文件。沿用模型的绝对本地 `NativePath` 校验；同组按 UTF-16 路径精确相等去重，大小写不折叠，跨组可引用同一路径。路径是否仍存在、文件与目录类型是否匹配尚未核验，之后 UI 接入时需要处理。

提交前先检查原配置、目标组、总条目数、路径字符总预算、同组重复和连续 ID 余量；失败不修改配置。成功分配稳定 ItemId，并只添加引用记录。会话沿用后台 I/O 工作者自动保存；保存失败或工作线程中断时移除本批 ID 并恢复 `next_item_id`。源文件从未交给存储层写入。
