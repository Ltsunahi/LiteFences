## 专用 Windows 测试环境的后续顺序

1. 用户指定可重置的 Windows 11 x64 测试虚拟机或专用会话，保存快照/测试前状态；记录构建、权限、显示器与 DPI。不得直接使用日常桌面做故障注入。
2. 先运行只读探测，检查宿主结构与 Shell 视图；Shell 不可用时记录失败，不继续盲目挂载。
3. 实现默认关闭的实验挂载适配器，验证父子样式、DPI、输入/焦点、失败降级和退出清理；不注入或隐藏全部原生图标。
4. 分别记录普通面板、实验桌面模式的 Win+D 50 次往返；后者需返回桌面后可见且可交互。当前工具不能发送 Windows 键，需要人工执行。
5. Explorer 重启 20 次，逐次记录旧宿主失效、新 Shell 视图就绪、旧结果丢弃、有限重试、窗口恢复与焦点。持续失败须安全降级，不无限增开线程/进程。
6. 分别验证普通应用覆盖、无边框全屏、独占全屏、锁屏/休眠与多屏 DPI。恢复操作不能抢占用户正在操作的应用焦点。
7. 保存逐次证据及缺陷；满足计划后才勾选 P0-03，并进入 P0-04 原生图标策略决策。

步骤 3 尚未实现，步骤 4–6 尚未执行；以上为验收顺序，不是完成记录。
