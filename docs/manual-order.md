# 组内手动排序

普通窗口内点选一个文件图标，再点击“引用前移”或“引用后移”，每次在同一分组中移动一位。首项不能前移、末项不能后移，相关按钮禁用；保存中、只读或无有效选择时不能提交。按稳定 GroupId/ItemId 操作，不按文件名查找。

顺序由配置中的 items 数组保存，自动保存并在重启时恢复。只移动同一个 Item 的数组位置，不生成新 ID，不改变分配器、路径或其他组，也不读写源文件。保存失败、提交失败或后台线程中断时恢复原顺序；既有移除/删除撤销记录不被排序消费。本版排序没有独立撤销历史，可用反方向按钮调整。

仍只有最多 24 个项目预览槽位，没有分页/滚动或拖动排序。此功能不等于组间移动引用；后者仍待开发。

自动化测试覆盖纯数据首尾/中间/原位/非法目标、保存与重启、保存失败及提交前/确认前线程中断。可见按钮与排序效果由实际窗口复验单独记录，不能用合成配置代替真实 Explorer 拖入。
